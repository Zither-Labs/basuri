# Learn Basuri — Swaras

# Swaras (Sa–Ni)

      Once you can hold a tone, learn the seven swaras. On a common beginner **C middle** natural map, Sa is all holes closed; each higher swara opens one more hole from the bottom.

    
    
      ## Fingering chart (6-hole natural)

      
        Holes left→right = upper (near embouchure) → lower. Filled = closed.

        
          SwarHolesAction
          SaAll closed
          ReOpen bottom
          GaOpen bottom two
          MaOpen bottom three
          PaOpen bottom four
          DhaOpen bottom five
          NiAll open
          Sa↑Upper octave later — tighter embouchure / overblow, not just louder air
        
      
    
    
      ## Practice

      
        - Drone Sa on the practice bar.

        - Hold Sa, then Re, back to Sa.

        - Add Ga and Ma — always return to Sa to check pitch.

        - Climb to Ni only when each step is clear.

      
    
    
      ## About Sa

      Some systems set Sa with only the **top three** holes closed. Pick one system for your flute and stay consistent. This page uses all-closed = Sa because it matches many first-week C-flute tutorials.
