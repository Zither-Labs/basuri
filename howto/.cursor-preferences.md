# Coding Preferences (Basuri room)

## Git & publishing (hard rule)

- **Never push to git unless the user explicitly asks.** Local edits/commits only when
  requested; publishing requires an explicit "push" every time.

## Repository consistency (always)

- Keep HTML ↔ Markdown twins in sync (`first-sound.html` ↔ `first-sound.md`, etc.).
- Shared theme / practice bar / paths / mobile nav: edit `../shared/` and sync — do not
  hand-edit room copies of those files.

## Scope

Absolute beginners first: embouchure and first tone before repertoire. The murali page
covers the **end-blown** (recorder-like) bamboo flute, distinct from side-blown basuri —
cultural context and a different blowing path, not a substitute for basuri embouchure
practice. Alankars/songs use real bansuri sample playback (`basuri-core.js`). Propose
pedagogy; wait for approval on large curriculum expansions.
