# Learn Basuri

Eastern bamboo flute for absolute beginners — hold, first sound, breath, daily
routine for tone, then one-hole steps / charts / alankars / songs. End-blown murali
(recorder-style) is a separate story from side-blown basuri.

Path: [choose](choose.md) → [hold](hold.md) → [first sound](first-sound.md) →
[breath](breath.md) → [routine](routine.md) → [one hole at a time](ladder.md) →
[fingering charts](swaras.md) → [listen](listen.md) → [alankars](alankars.md) →
[songs](songs.md). Optional: [make](make.md) · [murali](murali.md) ·
[venu](venu.md) · [resources](resources.md).
