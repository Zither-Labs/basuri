# Learn Basuri

Eastern bamboo flute for absolute beginners — first sound, practice routine, swaras,
alankars/songs with real bansuri playback, and the end-blown murali
(recorder-style, distinct from side-blown basuri).

Path: [choose](choose.md) → [first sound](first-sound.md) → [routine](routine.md) → [hold](hold.md) → [breath](breath.md) → [swaras](swaras.md) → [ladder](ladder.md) → [listen](listen.md) → [alankars](alankars.md) → [songs](songs.md) → [murali](murali.md) → [resources](resources.md).
