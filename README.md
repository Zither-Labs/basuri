# Learn Basuri

Interactive beginner guide to the Eastern bamboo flute (**bansuri** / **basuri**),
in the same Sangeet Yatra style as Piano, Guitar, and Singing.

**Live (when deployed):** https://bikashacharya.com/basuri/
